# Аудит данных (этап 1)

Дата проверки: 2026-11-14. Скрипты: `scripts/audit_images.py`, `scripts/build_metadata.py`. Результаты: `data/audit.csv`, `data/metadata.csv`.

## Целостность (п. 4.3.1 ТЗ)

- Файлов: **2906** (совпадает с п. 4.1 ТЗ), все `.jpg`.
- Не читаются (`cv2.imread`): **0**. Удалять нечего.
- Разрешение: у всех 1280×720.
- Имён, не подошедших под шаблон `Труба №… Плавка №<год>-<префикс><номер> Лист №…`: **0**.

## Состав по производителям (п. 4.3.2 ТЗ)

| Производитель | Префикс плавки | Фото | Доля |
|---|---|---|---|
| ПАО «ММК» | `В` (кириллица) | 1611 | 55,4% |
| АО «Уральская Сталь» | `Z` | 842 | 29,0% |
| АО «Уральская Сталь» | `V` | 453 | 15,6% |

Правило «префикс → производитель» проверено глазами на контрольных листах по 20 случайных фото на группу (seed 7):

- `В`: на всех видна подпись «ММК», сплошной трафаретный шрифт, три строки.
- `V` и `Z`: точечная маркировка (признак «Уральской Стали», п. 4.1), колонка вдоль края листа, чаще всего повёрнута примерно на 90°, встречаются перевёрнутые на 180°. По внешнему виду `V` и `Z` — один и тот же формат.
- Среди проверенных 60 фото маркировки «Северстали» (несколько строк под разными углами) не обнаружено. Проверка выборочная: полного отсутствия она не доказывает.

## Наблюдения, важные для следующих этапов

- **Дубликаты листов:** 7 пар «плавка + лист» (14 файлов) сняты дважды. В `split.csv` каждая пара должна попасть в одну выборку (этап 2). Ключ — `group_key`.
- **Оверлей камеры:** в левом верхнем углу каждого кадра «ГД42 + время». EasyOCR на пробном кадре прочитал только его. Нужна маска (этап 3).
- **Кадры без читаемой маркировки:** среди 40 просмотренных фото `V`/`Z` заметная часть имеет маркировку частично за кадром или едва различимую. Категория «нечитаемо» (этап 2) для этих групп, вероятно, будет заметной по объёму. Точное число даст разметка.
- **Повороты:** маркировка `В` наклонена под разными углами, у `V`/`Z` бывают перевёрнутые на 180°. Перебора 0/90/180/270° будет недостаточно без учёта произвольного наклона (этап 3).

## Окружение

- Системный Python 3.9.6 не подходит (НФТ 3: 3.10+). Используется Python 3.11.17 в `.venv`, созданном через `uv`.
- Установка зависимостей (`easyocr`, `opencv-python-headless`, `flask`, `numpy`, `pandas`, `pytest`, вместе с `torch`) заняла ~54 с.
- EasyOCR (`Reader(['ru','en'], gpu=False)`) запускается на CPU. Веса: ~94 МБ (`craft_mlt_25k.pth`, `cyrillic_g2.pth`), качаются при первом запуске в `~/.EasyOCR/model`. Обработка одного кадра ~2 с.
