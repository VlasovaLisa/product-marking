# Решение о читаемости тестовых кадров (критерий 11 ТЗ)

Зафиксировано 2026-11-15, **до** итогового прогона на тестовой выборке (тест ещё не запускался).

- Файл решения: `data/readability.csv`, 581 строка (все тестовые кадры), SHA-256: `3994cb9dbd6796ca62afb2114f320a0ed728a5a373d9b2f9ce059920090b22ce`.
- Метки ставил человек (заказчик/исполнитель проекта) инструментом `scripts/readability_tool.py`, без просмотра ответов OCR.
- Значения: `readable` — номер плавки виден целиком; `partial` — виден только фрагмент; `unreadable` — номера плавки на кадре не видно.
- Исключаются из CER только `unreadable` (флаг `--exclude-unreadable`); количество исключённых ниже.

| Формат | readable | partial | unreadable | всего |
|---|---|---|---|---|
| ММК (`В`) | 214 | 59 | 49 | 322 |
| `V` | 59 | 18 | 14 | 91 |
| `Z` | 100 | 25 | 43 | 168 |
| **Все** | **373** | **102** | **106** | **581** |

Исключается **106 из 581 кадра (18%)**. В отчёте приводятся три цифры CER: по всему тесту, без `unreadable`, только по `readable`.

Файл `data/readability.csv` после этой записи не меняется. Проверка: `shasum -a 256 data/readability.csv` должна совпасть с суммой выше.
