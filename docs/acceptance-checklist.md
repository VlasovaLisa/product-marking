## Что осталось до сдачи

Подтверждено пользователем 2026-11-15: установка по README, CER по плавке и листу, замена EasyOCR на PaddleOCR, работа в Firefox, отсутствие «Северстали».

Осталось:

1. Согласовать исключение 106 из 581 кадров («не читается») в варианте отчёта без них.
2. Пройти проверку в Chrome по файлам из `demo/` (в том числе сообщение «Маркировка не распознана»).
3. Сделать коммит (сейчас репозиторий без единого коммита).
