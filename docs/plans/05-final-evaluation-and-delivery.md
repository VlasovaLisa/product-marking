## Задачи

### Итоговая оценка на тесте (критерии 4, 6, 9, 11)
- [ ] Перед прогоном зафиксировать конфиг конвейера и версию кода (git-тег, например `eval-final`). После прогона на тесте конвейер не подкручивается — иначе тест перестаёт быть независимым (п. 4.2).
- [ ] `scripts/evaluate.py --split test`: CER общий (micro), CER по каждому производителю (и по `marking_format` `V`/`Z`), время на изображение (среднее, медиана, максимум), оборудование, на котором проводился замер.
- [ ] Число исключённых `unreadable` изображений по производителям и ссылка на то, что решение зафиксировано на этапе 2 до тестирования (критерий 11).
- [ ] Отдельно — CER на `partial` изображениях (справочно).
- [ ] Анализ типичных ошибок: путаница похожих символов, пропуски строк, точечная маркировка.

### Проверка поворотов (критерий 5, ФТ 3)
- [ ] Прогон на повёрнутом тестовом наборе (90°, 180°, 270°): доля правильно определённых ориентаций и CER по каждому углу.
- [ ] Ручная демонстрация в веб-интерфейсе на нескольких повёрнутых изображениях.

### Отчёт
- [ ] `docs/evaluation-report.md`: метод (разбиение, правила нормализации, формула CER), результаты по всем пунктам выше, выбранная модель и её параметры, ограничения.
- [ ] Критерий 9: проверка проведена на фактически имеющихся производителях (ММК, «Уральская Сталь»). Отсутствие «Северстали» явно указано как согласованное с заказчиком (или открытое) расхождение — см. [00-overview.md](00-overview.md).

### Воспроизводимость (критерии 1, 8, НФТ 6)
- [ ] `requirements.txt` с зафиксированными версиями всех пакетов.
- [ ] `README.md`: требования (Python 3.10+, ОС, рекомендованное оборудование, GPU не обязателен), установка (venv, `pip install -r requirements.txt`), загрузка весов модели (EasyOCR скачивает их при первом запуске — указать, куда и сколько весят, и как положить заранее без интернета), запуск сервера, адрес в браузере, запуск оценки, структура проекта.
- [ ] Сведения об OCR-модели: библиотека, версия, языки, параметры конвейера (можно ссылкой на `docs/ocr-model-choice.md`).
- [ ] Проверка «с нуля»: чистая машина или чистый venv, установка строго по README с замером времени (≤ 30 мин).
- [ ] Итоговые тесты (`pytest`) проходят.

## Критерии готовности

- CER ≤ 30% на тесте, время ≤ 60 с — зафиксированы в отчёте.
- Установка по README с нуля укладывается в 30 минут.
- Все пункты чек-листа приёмки закрыты или явно отмечены как согласованное расхождение.

## Риски этапа

- CER на тесте выше 30%, хотя на настройке укладывался → честно зафиксировать результат и анализ ошибок. Подкручивать конвейер под тест нельзя; если доработка нужна, она делается на выборке настройки с повторным однократным прогоном теста, и это явно отмечается в отчёте.
- Веса EasyOCR не скачиваются без интернета → инструкция по ручной загрузке в README.
- Установка torch съедает большую часть 30 минут → CPU-версия torch, указание в README.
