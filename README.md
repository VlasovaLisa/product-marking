# Система автоматического считывания маркировки продукции

Веб-приложение, которое распознаёт буквенно-цифровую маркировку на фотографиях металлических прокатных листов (ММК, «Уральская Сталь») готовой предобученной OCR-моделью и позволяет вручную исправить результат. Учебный проект, MVP по [техническому заданию](docs/tech-task.pdf).

## Результаты

Итоговая оценка на независимой тестовой выборке (581 фотография, 20% набора), CER по номеру плавки и листа:

| | ММК | «Уральская Сталь» V | «Уральская Сталь» Z | Всего |
|---|---|---|---|---|
| Вся тестовая выборка | 20,4% | 31,1% | 46,4% | **24,4%** |
| Без кадров, где номер плавки не виден | 14,5% | 24,0% | 38,4% | **17,8%** |

Цель ТЗ — CER не более 30%. Время обработки одного фото: в среднем 12,6 с, максимум 16,3 с (CPU, без GPU). Подробности — в [отчёте о проекте](docs/Власова_отчет_Маркировка_продукции.pdf) и [docs/evaluation-report.md](docs/evaluation-report.md).

## Требования

- Python 3.10 или новее (проверено на 3.11).
- Компьютер без видеокарты: всё считается на процессоре. Рекомендуется не менее 8 ГБ ОЗУ и 3 ГБ свободного места.
- Доступ в интернет при первой установке и первом запуске (пакеты и файлы моделей).
- Браузер: актуальный Google Chrome или Firefox.

## Установка

```bash
python3 --version        # должен быть 3.10 или новее
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```


## Запуск веб-приложения

```bash
python -m src.app
```

Подождите 15–30 секунд, пока загрузится модель, затем откройте в браузере http://127.0.0.1:8000.

1. Нажмите «Выбрать изображение» и укажите фото в формате JPG, JPEG или PNG (до 10 МБ). Ниже появится превью.
2. Нажмите «Распознать». Обработка одного кадра занимает 10–20 секунд.
3. Результат появится в поле ниже. Его можно править прямо в поле. Если маркировка не найдена, будет сообщение «Маркировка не распознана», а поле остаётся доступным для ручного ввода. Если результат неуверенный, приложение предупредит об этом, текст всё равно покажет.

Работа в командной строке после запуска сервера не нужна.

## Оценка качества

Исходные фотографии в репозиторий не входят. Положите их в папку `images/` в корне проекта или укажите путь к ним в переменной окружения `IMAGES_DIR`. Таблицы, полученные на шагах ниже, уже лежат в `data/`, результаты прогонов — в `reports/`. Подготовка данных (один раз):

```bash
python scripts/audit_images.py        # проверка файлов
python scripts/build_metadata.py      # data/metadata.csv: плавка, лист, производитель
python scripts/split_dataset.py       # data/split.csv: разбиение 80/20 (защищён от перезаписи)
python scripts/build_references.py    # data/references.csv: эталон из имён файлов
python scripts/make_rotated_set.py    # data/rotated: повёрнутые копии для проверки поворотов
```

Оценка на выборке настройки (по умолчанию 40 кадров на формат, конфигурация по умолчанию):

```bash
python scripts/evaluate.py --name my-run
python scripts/evaluate.py --rescore my-run          # повторная сводка по сохранённому результату
python scripts/evaluate.py --name rot --rotated      # повёрнутые копии (90, 180, 270)
```

Итоговая оценка на тесте закрыта флагом `--final` и выполняется один раз. Пометка читаемости тестовых кадров: `python scripts/readability_tool.py` (порт 5002).

Описание метрики, эталона и всех замеров: [docs/experiments.md](docs/experiments.md). Выбор модели и итоговая конфигурация: [docs/ocr-model-choice.md](docs/ocr-model-choice.md). Решение о нечитаемых кадрах: [docs/readability-decision.md](docs/readability-decision.md).

## Структура

| Путь | Назначение |
|---|---|
| `src/app.py`, `src/templates/` | веб-приложение (Flask) |
| `src/pipeline.py` | конвейер: подготовка, выбор угла, OCR, постобработка |
| `src/preprocessing.py`, `src/postprocessing.py`, `src/localization.py` | шаги конвейера |
| `src/engines.py` | подключение PaddleOCR и EasyOCR |
| `src/metrics.py`, `src/text.py`, `src/references.py` | метрика CER и правила сравнения текста |
| `scripts/` | подготовка данных, оценка, инструменты пометки |
| `data/` | метаданные фото, разбиение на выборки, эталон, решение о читаемости |
| `reports/` | результаты всех прогонов оценки (CSV) |
| `report/` | сборка PDF-отчёта: `collect_numbers.py`, `build_report.py`, графики |
| `docs/` | ТЗ, отчёт, планы этапов, журнал экспериментов, решения |
